ABOUT THE ORGANIZATION

Connected software, built in the open.

Gothwad Tech's public work spans identity, web services, communication, Android applications and developer tools. This page explains how those projects fit together—and where to verify the details.

OUR PURPOSE

Make useful software feel connected.

Gothwad Tech is developing a collection of digital products and software projects. Some services are designed to share an identity layer; others are standalone applications with their own goals, codebases and licences.

The public account profile describes three recurring areas of work: shared identity, edge-oriented web products, and native Android and TV software. The source repositories and documentation remain the authority for implementation and current status.

PUBLIC PRINCIPLES

What visitors can rely on.

The public record is intentionally more modest than an advertising page.

  • Repository first: use each project’s current README, releases, licence and docs for exact claims.
  • No implied launch: a repository, domain or product name does not establish production availability or support.
  • Separate licences: terms vary by project; upstream-derived code keeps its own attribution and licensing requirements.
  • Clear attribution: project summaries describe repositories and product scope, not the personal authorship of every contributor.
  • Distinct websites: GothwadTech.com is the product and app discovery portal; this GitHub Pages site is the company-information and public-source hub.
