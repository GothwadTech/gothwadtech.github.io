HOW WE DESCRIBE THE WORK

Useful information, without inflated claims.

Public repositories can be at very different stages. Clear scope helps visitors know what they can verify and where to go next.

Source before slogans

Read each project’s README, licence and release history for implementation details. The repository, not a summary card, is the source of truth.

Availability is separate

A public repository or product URL does not by itself mean a service is currently available, production-ready or supported.

Licences differ

Projects have their own licensing and attribution terms. Check the exact repository before copying, redistributing or deploying code.

QUICK ANSWERS

About this Gothwad Tech website

Use this site for company context and public source; use the separate portal to open ecosystem apps.

What is GothwadTech.github.io for?

It is the public information and discovery hub: company context, product descriptions, leadership references, documentation portal links and a directory of public GitHub repositories.

Where do I open Gothwad Tech apps?

Use GothwadTech.com, the separate ecosystem portal. Individual app availability can vary.

Are all public repositories released products?

No. The account has product code, Android companion apps, docs, templates, experiments and upstream-derived repositories. Check each repo’s README, release history and licence.

Where can developers find setup and API documentation?

Start at docs.gothwadtech.com. The portal covers selected products and integrations; it does not claim complete documentation for every repository.
