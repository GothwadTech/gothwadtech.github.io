# Gothwad Tech — public information hub

This repository serves <https://gothwadtech.github.io/>: company information, source-linked product discovery, leadership references, trust/status boundaries and a searchable public-repository directory. It is **not** the app-launching portal; use the separate [GothwadTech.com](https://gothwadtech.com/) site to discover the ecosystem. Developer guides remain in the separate [docs portal](https://docs.gothwadtech.com/); this site links there and does not duplicate technical documentation.

## Stack and deployment

The site is plain HTML, CSS and vanilla JavaScript. Content is static and served from the repository root and subdirectories; there is no framework, package manager, backend, build step or analytics integration. GitHub Pages should publish branch `main` from `/(root)`. See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Accuracy and privacy

A public repository does not by itself imply a released, production-ready, available or supported product, nor does public visibility grant reuse rights. Check the exact project’s current source, release history, licence and upstream notices. Unknown company or operational information is labeled unpublished rather than guessed. The site is English-only and intentionally uses no third-party analytics. See [docs/CONTENT_POLICY.md](docs/CONTENT_POLICY.md) and the [72-item implementation register](docs/WEBSITE_IDEAS.md).
