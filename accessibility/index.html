ACCESSIBILITY INFORMATION

Built for clear, direct access.

This static information site uses semantic HTML and keyboard-accessible navigation patterns. No independent WCAG conformance audit or certification is claimed.

Current approach

The site includes a skip link, semantic headings and landmarks, text labels, visible focus styles, responsive layouts and progressive enhancement for menus and filters.

Known limits

Product logos are decorative where the adjacent name already identifies the project. Some pages contain third-party links and assets whose accessibility is outside this site’s control. We do not claim that every content item has been independently audited.

Feedback

If you encounter a barrier on this information site, use the general contact routes provided on the contact page. Please avoid sending sensitive personal information.
