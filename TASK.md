# Project status

## Purpose

This repository contains a public software-project showcase, separate from the full official website in [`GothwadTech/website`](https://github.com/GothwadTech/website). The account's special profile README lives separately in `GothwadTech/gothwadtech`.

The site is a static HTML, CSS, and vanilla JavaScript page. Product summaries link to source repositories and avoid claims that may be stale or unverified.

## Deployment

The site is hosted at <https://gothwadtech.github.io/> directly from the repository root. Configure **Settings → Pages → Deploy from a branch → `main` → `/(root)`**. No GitHub Actions workflow or build step is needed. See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
