A NOTE ON RESPONSE AND SECURITY

Use public, project-scoped channels.

Public repository activity does not imply a service-level agreement or guaranteed response time. Do not post passwords, access tokens, private account details or sensitive personal data in public issues.

For security reports, follow the security policy or reporting instructions in the affected repository. If a repository has no published policy, do not assume a private channel or response commitment that is not stated there.
