# Public information and content policy

This repository is the English-language public-information and source-discovery hub for Gothwad Tech. It is distinct from the app and ecosystem portal at [GothwadTech.com](https://gothwadtech.com/). Developer documentation is maintained separately at [docs.gothwadtech.com](https://docs.gothwadtech.com/); this website links to that portal and does not duplicate guides, APIs, setup instructions or troubleshooting.

## Source and review rules

1. Prefer official Gothwad Tech repositories, the public ecosystem catalogue, and the user-confirmed leadership details as primary sources.
2. Use literal, modest summaries. Do not repeat unverified superlatives, performance figures or usage metrics from marketing copy.
3. Link to the source rather than copying frequently changing setup, deployment, API or policy instructions.
4. Describe portal URLs as listings, not as uptime checks. A URL, public repository, build or product name does not prove current availability, release maturity, production readiness or support.
5. Do not infer open-source permissions from public visibility. Show repository license metadata with a dated review note; respect upstream and fork attribution.
6. Label facts not provided for publication as “Not published,” “No matching public repository found,” or equivalent. Do not invent a substitute.
7. Keep this information hub, GothwadTech.com and docs.gothwadtech.com visibly distinct.
8. Leadership is limited to Pawan Gothwad (Founder), Yuvkesh Meena (CEO), and Vishnu (Co-founder). Do not add roles, biographies or team members without explicit approval.
9. Use English only. Do not embed third-party analytics or tracking; no analytics is the selected site policy.
10. Dated inventory counts and repository licence fields are snapshots, not live guarantees. Refresh them from GitHub before changing the review date.

## Never invent or imply

- employee counts, biographies, clients, testimonials, awards, legal status or company registrations;
- usage, revenue, latency, uptime, rankings, performance comparisons or guarantees;
- security/privacy properties not explicitly supported by current project documentation;
- contact addresses, support channels, response-time commitments or product maturity;
- release dates or roadmap commitments that have not been formally approved;
- published privacy, legal, press, careers, events or status information that is not publicly available.

For general company information, link to the official site. For technical guidance, link to the separate documentation portal. For implementation and licensing, link to the exact project repository. Record substantive content and deployment changes in `TASK.md` and run static QA across HTML pages, local assets, canonical URLs, sitemap entries and internal links before publishing.
