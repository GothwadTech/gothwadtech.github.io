# Public profile content policy

This repository is being prepared as the GothwadTech account's GitHub Pages
showcase. The account profile README will live in the separate
`GothwadTech/gothwadtech` repository. The primary company website lives in
[`GothwadTech/website`](https://github.com/GothwadTech/website).

## Before describing a project

1. Open its current public repository and read the README.
2. Use only facts supported by that source or the central
   [documentation portal](https://docs.gothwadtech.com).
3. Link to the primary source instead of copying frequently changing setup,
   deployment, or API details.
4. Describe unverified service availability cautiously. A URL or repository
   doesn't prove a service is currently available.
5. Do not turn a public repository into an authorship, release, or support claim.

## Never invent or imply

- employee counts, biographies, clients, testimonials, awards, or company
  registrations;
- usage, revenue, latency, uptime, performance comparisons, or guarantees;
- security/privacy properties not explicitly supported by current project docs;
- contact addresses, support channels, or project maturity.

For general company information, link to the official site. For technical
information, link to the repository or documentation page. Record substantive
changes in `TASK.md` and check the page with a static HTTP server before
publishing.
