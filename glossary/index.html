PLAIN-LANGUAGE GLOSSARY

A few terms used around this site.

This glossary explains how to read the public project directory. It is not an engineering manual or product documentation.

Portal listing
An entry or URL shown by the public ecosystem portal. It does not certify that a service is currently reachable or supported.
Public repository
A GitHub repository whose contents can be viewed publicly. Public visibility alone does not grant reuse rights.
Release
A version or downloadable artifact published by a project. A repository may have no public releases, and this site does not infer a release from source code.
Licence
Terms describing permitted use of source code and other work. Check the exact repository and any upstream project notices.
Fork
A copy of another repository that may retain upstream code, history and licence obligations.
Availability
Whether a service is reachable at a particular time. A directory link is not a live availability check.
Documentation portal
The separate site at docs.gothwadtech.com; technical guides are maintained there rather than duplicated here.
